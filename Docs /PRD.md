# Product Requirements Document (PRD)

## Product Name

Wama - Personal Wadrobe management app

## Vision

Help users digitize their wardrobe, create better outfits from existing clothes, and make smarter fashion purchases.

## Problem Statement

Users:

* Forget what they own
* Buy duplicate clothing items
* Struggle to create outfits
* Waste money on unnecessary purchases
* Cannot evaluate whether a Pinterest-inspired look can be recreated from their wardrobe

## Target Audience

Primary:

* Working professionals (25–45)
* Fashion-conscious individuals
* Frequent online shoppers

Secondary:

* Stylists
* Fashion influencers
* Couples/families managing shared wardrobes

## Success Metrics

MVP:

* 70% of users upload >20 items
* Average 3 outfit recommendations per week
* 30-day retention >25%

Business:

* Affiliate purchase conversions
* Premium subscription upgrades
* User engagement with styling recommendations

---

# MVP Features

## Feature 1: Wardrobe Registry

### Description

Digitally catalog all wardrobe items.

### Input Methods

1. Manual Entry
2. Clothing Photo Upload
3. Invoice/Bill Upload

### Captured Attributes

* Category
* Brand
* Color
* Size
* Price
* Purchase Date
* Images
* Tags

### Acceptance Criteria

* User can add/edit/delete items
* User can attach multiple images
* Item searchable by tags and category

---

## Feature 2: Smart Receipt Processing

### Description

Extract purchase information from invoices.

### Supported Inputs

* PDF invoices
* Screenshots
* Photos

### Extract

* Brand
* Purchase Date
* Amount
* Product Name

### Acceptance Criteria

* > 80% extraction accuracy
* User can manually correct data

---

## Feature 3: AI Clothing Classification

### Description

Automatically identify clothing attributes.

### Detect

* Category
* Color
* Pattern
* Style
* Season

### Acceptance Criteria

* Classification completes in <10 seconds
* User can override AI labels

---

## Feature 4: Digital Closet

### Description

Visual wardrobe inventory.

### Filters

* Category
* Color
* Occasion
* Season
* Brand

### Acceptance Criteria

* Responsive inventory view
* Search functionality

---

## Feature 5: Outfit Recommendation Engine

### Description

Generate outfits from existing wardrobe.

### Inputs

* Occasion
* Season
* Weather
* Style Preference

### Output

* Complete outfit suggestions
* Explanation of recommendations

### Acceptance Criteria

* Generate 3–5 outfit combinations
* Use only owned wardrobe items

---

## Feature 6: Wardrobe Analytics

### Metrics

* Total wardrobe value
* Number of items
* Most used items
* Least used items
* Cost-per-wear

### Acceptance Criteria

* Dashboard loads in <2 seconds
